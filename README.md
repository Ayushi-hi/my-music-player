# 🎶 My Music Player

A simple and interactive web-based music player built using HTML, CSS, and JavaScript. This project allows users to play, pause, and control audio tracks with a clean and responsive interface.

## 🚀 Features
- Play and pause music
- Next and previous track controls
- Audio progress bar
- Responsive UI design
- Smooth user experience

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## ▶️ How to Run the Project
1. Clone this repository:
   git clone https://github.com/Ayushi-hi/my-music-player.git

2. Open the project folder.

3. Open `index.html` in your browser.
